
# 5-minute quickstart

```bash
git clone <your-repo-url>
cd riddell-executive-performance-cockpit
python -m venv .venv
```

Activate the environment and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL shown by Streamlit.

## Demo flow

Use this sequence in the customer conversation:

1. **Executive Cockpit** — establish enterprise pulse.
2. **KPI Story** — show how one KPI becomes an explainable business story.
3. **Cross-Process Story** — connect procurement, production, fulfillment, and finance.
4. **Ask Riddell** — demonstrate the future conversational layer.
5. **KPI Trust Card** — close by showing governance, definition, source, and lineage.

## Before using with Riddell

Replace the simulated values with the customer-approved KPI list and definitions.
